# QR Customizer

Generador y personalizador de códigos QR con diseño brutalista.

![QR Customizer](https://img.shields.io/badge/QR-Customizer-FF90E8?style=for-the-badge&labelColor=000000)

## ✨ Características

- 🔗 **Múltiples tipos de QR**: URL, Texto, Email, Teléfono, WiFi, vCard
- 🎨 **Personalización completa**: Estilos de puntos, esquinas, colores, degradados
- 🖼️ **Logo personalizado**: Agrega tu logo o imagen en el centro del QR
- 📐 **Ajuste de tamaño**: Control total sobre dimensiones y márgenes
- 📥 **Descarga flexible**: Exporta en PNG, SVG o JPEG
- 🎯 **Vista previa en tiempo real**: Ve los cambios al instante
- 💅 **Diseño brutalista**: Inspirado en Gumroad

## 🚀 Instalación

```bash
npm install
npm run dev
```

## 🛠️ Tech Stack

- React 18 + TypeScript
- Vite
- qr-code-styling
- CSS Brutalista

## 📦 Build

```bash
npm run build
```
